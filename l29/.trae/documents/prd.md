## 1. 产品概述

基于WebGPU Compute Shader的10万粒子SPH（光滑粒子流体动力学）实时流体模拟系统，所有物理计算在GPU端完成，CPU零负担。面向图形学爱好者、物理仿真研究者和创意开发者，提供浏览器内即可体验的工业级流体模拟。

## 2. 核心功能

### 2.1 功能模块

1. **模拟主页面**：3D流体粒子渲染视口、参数控制面板、性能监控

### 2.2 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 模拟主页面 | 3D渲染视口 | 基于InstancedMesh的10万粒子实时渲染，支持旋转/缩放/平移交互，粒子颜色映射速度或密度 |
| 模拟主页面 | SPH物理引擎 | GPU Compute Shader实现：密度计算、压力力计算、粘性力计算、欧拉时间积分、边界碰撞检测 |
| 模拟主页面 | 参数控制面板 | 可调节粘度系数、静止密度、气体常数（刚度）、重力、时间步长、粒子半径等参数 |
| 模拟主页面 | 性能监控 | 实时FPS计数、GPU计算耗时、粒子数量显示 |
| 模拟主页面 | 场景控制 | 暂停/继续、重置模拟、颜色映射模式切换（速度/密度/压力） |

## 3. 核心流程

用户打开页面后，系统自动检测WebGPU支持，初始化GPU缓冲区和粒子位置，启动模拟循环。每一帧依次执行：空间哈希构建→密度计算→压力/粘性力计算→时间积分→边界碰撞→渲染输出。用户可通过侧边控制面板实时调整物理参数，参数变更即时生效。

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深蓝黑背景(#0a0e1a) + 青蓝色流体粒子 + 琥珀色(#f59e0b)高亮交互
- **风格**：赛博工业风 — 暗色背景搭配发光粒子效果，控制面板采用毛玻璃质感
- **字体**：JetBrains Mono（数据/代码风格）+ Space Grotesk（标题/界面）
- **布局**：全屏3D视口 + 右侧浮动毛玻璃控制面板
- **按钮样式**：圆角微光边框，hover发光效果

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 模拟主页面 | 3D渲染视口 | 全屏Canvas，深色背景，粒子发光效果，OrbitControls交互 |
| 模拟主页面 | 控制面板 | 右侧浮动面板，毛玻璃背景，分组滑块控件，实时数值显示 |
| 模拟主页面 | 性能监控 | 左上角半透明HUD，FPS/帧时间/粒子数 |
| 模拟主页面 | 顶部标题栏 | 项目名称 + 简要说明，半透明条 |

### 4.3 响应式

- 桌面优先设计，3D视口占满屏幕
- 控制面板在小屏幕可折叠/收起
- 最小支持1280px宽度

### 4.4 3D场景指引

- **环境**：深蓝黑色虚空背景，无环境贴图
- **光照**：单一方向光 + 环境光，粒子自发光
- **相机**：透视相机，45°俯视角，OrbitControls自由旋转
- **粒子**：小球体实例，颜色映射物理量（速度→蓝到红渐变）
- **后处理**：可选泛光(Bloom)效果增强发光感
- **性能预算**：10万粒子@60fps，GPU Compute Shader全流程<5ms
