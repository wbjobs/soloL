## 1. 产品概述

边缘AI人流检测与区域布防系统——基于WebRTC低延迟视频传输与浏览器端Wasm轻量YOLO推理，实现实时人流检测、热力图聚合、多边形区域布防与越界Web Push告警的一体化边缘计算平台。

- 面向安防运维人员和场所管理者，解决传统人流监控部署复杂、延迟高、成本高的问题
- 核心价值：零客户端安装、浏览器即推理、5秒级热力图更新、秒级越界告警

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|

3. **区域布防页面**：多边形绘制工具、布防规则配置、告警历史记录

## 3. 核心流程

用户通过浏览器打开系统，上传视频文件或配置RTSP流地址，后端接收后转码为WebRTC格式推送到前端。前端通过Wasm加载YOLO模型对视频帧进行实时推理，绘制检测边界框。每5秒将检测结果上报后端，后端聚合生成热力图数据。用户可在视频画面上绘制多边形布防区域，当检测到人员越界时，系统触发Web Push通知。


## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深色科技风——#0A0E17（背景深蓝黑）、#00E5A0（霓虹绿强调）、#FF3D71（告警红）
- 次色调：#1A1F2E（卡片深灰蓝）、#2A3040（悬停态）
- 按钮风格：圆角6px，霓虹绿边框发光效果，告警按钮红色脉冲动画
- 字体：Rajdhani（数据/标题，科技感）+ Source Sans 3（正文）
- 布局风格：左侧视频大屏为主，右侧折叠面板为数据统计，顶部导航栏
- 图标风格：线性描边图标，霓虹绿/白色，与暗色主题统一

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 监控大屏 | 视频播放区 | 深色背景，视频居中占满，绿色边界框叠加，底部控制条 |
| 监控大屏 | 检测叠加层 | Canvas半透明层，绿色描边边界框，白色标签+置信度百分比 |
| 监控大屏 | 人流统计面板 | 右侧滑出面板，数字大字显示计数，小型折线图趋势 |
| 监控大屏 | 热力图叠加 | 红黄渐变半透明热力图层，可调节透明度滑块 |
| 视频源管理 | 上传视频 | 拖拽区域，虚线边框，上传进度条，缩略图预览 |
| 视频源管理 | RTSP配置 | 表单输入框，连接状态指示灯（绿/红/黄），测试连接按钮 |
| 区域布防 | 多边形绘制 | Canvas覆盖层，顶点拖拽手柄，区域半透明填充，右侧属性面板 |
| 区域布防 | 告警历史 | 列表卡片，时间戳+缩略图+区域名，红色边框高亮未读 |

### 4.3 响应式设计

- 桌面优先设计，主屏1920x1080为基准
- 视频区域自适应容器宽度，保持16:9比例
- 移动端：视频全屏，统计面板底部抽屉，布防操作需横屏
