## 1. 产品概述

基于增量式隐马尔可夫模型（Incremental HMM）的金融时序异常检测与根因定位平台。系统支持股票/外汇等金融时序数据（最多10万个时间点），通过增量式Forward-Backward算法实现在线更新避免全量重训练，利用Viterbi解码的对数似然阈值进行异常检测，并通过SHAP值定位异常区间内的特征重要性根因，提供Plotly交互式图表与滑动窗口回测功能。

- 目标用户：量化分析师、风控工程师、金融数据科学家
- 核心价值：实时增量训练降低计算开销，异常检测+根因定位一站式解决，交互式可视化辅助决策

## 2. 核心功能

### 2.1 功能模块

1. **数据管理页**：数据上传（CSV）、示例数据加载、数据预览、特征选择
2. **模型训练与检测页**：HMM参数配置、增量式训练、异常检测、Viterbi解码结果
3. **根因分析页**：异常区间SHAP值计算、特征重要性排序、根因可视化
4. **回测验证页**：滑动窗口回测配置、准确率/召回率/F1指标、回测结果可视化

## 3. 核心流程

1. 用户上传CSV或加载示例数据 → 系统解析并预览
2. 用户配置HMM参数 → 系统执行增量式训练（Forward-Backward在线更新）
3. 训练完成后 → 系统通过Viterbi解码计算对数似然 → 基于阈值标记异常点
4. 用户选择异常区间 → 系统计算SHAP值 → 展示特征重要性根因
5. 用户配置回测参数 → 系统滑动窗口遍历 → 输出检测准确率指标

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深色系（#0a0e17 深蓝黑背景）搭配青绿荧光色（#00f5d4）作为强调色
- 辅助色：琥珀色（#f59e0b）标记异常，冷灰色（#6b7280）辅助文字
- 字体：JetBrains Mono（数据/代码区域），Outfit（标题/正文）
- 布局：左侧导航栏 + 右侧内容区，卡片式模块布局
- 图标：lucide-react，线形风格
- 动画：页面切换淡入，数据加载脉冲，异常点闪烁
